# OpenRouter Model Explorer - PRD

## Vision
Enable developers to discover, test, compare, and benchmark AI models via OpenRouter in one Android app.

## Problem
Developers manually switch models to compare performance, which is slow and inefficient.

## Target Users
- Android Developers
- AI Engineers
- Students
- Backend Developers

## Goals
- Discover free models
- Compare model outputs
- Benchmark performance
- Save history

## MVP Features
- Model Explorer
- AI Playground
- Model Comparison
- History
- Favorites

## Success Metrics
- Daily Active Users
- Prompts executed
- Comparisons run
- Session duration

## Out of Scope
- Auth
- Cloud sync
- Payments
